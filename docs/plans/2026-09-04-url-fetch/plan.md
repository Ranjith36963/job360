## Risks

- **The guard is the kind of code that looks right and is not.** Every one of the ten
  guards in `drill_registry.py`'s docstring was correct-looking code in the wrong
  position. Mitigation: the drill is not optional and its negative control (case 10) is
  held to the same standard as the breaks, so "deny everything" cannot pass.
- **`GuardedResolver` is an aiohttp internal contract.** `AbstractResolver` is public but
  its return shape (`[{hostname, host, port, family, proto, flags}]`) is version-sensitive,
  and the pin is `aiohttp>=3.14.1` with no upper bound. Mitigation: item 8 asserts the
  connector actually used our resolver (one call per hop), so an aiohttp change that
  silently bypasses it turns a test red rather than a guard off. Flag this explicitly to
  the reviewer.
- **The peername re-check may be `None` under `aioresponses`.** A mocked response has no
  real transport, so the check must treat "no peer information available" as **deny in
  production, skip in a mocked test** — and that branch is exactly where a real bypass
  would hide. Mitigation: the branch is driven by an explicit injected flag, never by
  sniffing whether we are under test, and item 9 forces a *wrong* peername rather than a
  missing one.
- **The heuristic rung has no reference implementation** (spec C2). Mitigation: fixtures
  saved from real pages, and the fallback is paste.
- **Stacked branch.** `feat/url-fetch` sits on `feat/application-spine`, which the owner
  has not merged. If slice 2 changes `bring.py` after this branch cuts, the rebase is on
  one file and must be done deliberately — union-merge, then re-run the targeted gate; the
  breakage hides in the file git merged *cleanly*.
- **CI has no LLM keys and no network.** Nothing here needs either — that is by design,
  and it is also why C1 (the bot walls are unproven offline) is a real limit and the
  verifier step is not optional.
- **Windows full-suite flake** (psycopg exit 139 on a second back-to-back run) — targeted
  gate locally, Linux CI is the verdict.
